# CONSTITUTION.md  
**Proyecto:** Reproductor Web3 para Entretenimiento  
**Autor:** Mauricio Vergara Miranda  
**Agencia:** Ingeniería Web Miranda  
**Metodología:** Spec‑Driven Development (SDD)  
**Contexto:** Proyecto derivado de sitio académico sobre etiquetas HTML audiovisuales (Maestría en Ingeniería Web, temática Ska‑Jazz).  

---

## 1. Principios de Identidad
- **Estética visual:** Azul eléctrico + contrastes blanco/amarillo.  
- **Narrativa temática:** Inspiración en la música **Ska‑Jazz** como metáfora de ritmo, improvisación y fusión tecnológica.  
- **Tono consultivo‑tecnológico:** Lenguaje claro, innovador y profesional.  

---

## 2. Objetivos del Proyecto
- Evolucionar un reproductor audiovisual clásico hacia un **ecosistema Web3 interactivo**.  
- Integrar **NFTs coleccionables**, **gamificación social** y **recompensas verificables**.  
- Mostrar en el portafolio la capacidad de unir **HTML audiovisual básico** con **tecnologías emergentes**.  

---

## 3. Lineamientos Técnicos
- **Frontend:** React + Framer Motion + Web3.js/Ethers.js.  
- **Backend:** NodeJS + Express + Prisma.  
- **Base de Datos:** Supabase (PostgreSQL + pgvector).  
- **Blockchain:** Ethereum/Polygon para minting de NFTs y tokens ERC‑20.  
- **Integración previa:** Reutilizar el sitio de etiquetas HTML como base conceptual y narrativa.  

---

## 4. Especificaciones Funcionales
- **Hotspots interactivos:** Overlays dinámicos sobre video para trivia, minijuegos y contenido extra.  
- **Coleccionables digitales:** Escenas convertidas en NFTs con opción de "Mint to Wallet".  
- **Gamificación:** Tokens acumulables, logros y ranking social.  
- **Panel de usuario:** Colección de NFTs, recompensas y estadísticas.  
- **IA aplicada:** Recomendaciones personalizadas con pgvector según patrones de interacción.  

---

## 5. Filosofía de Innovación
- **Improvisación Ska‑Jazz:** Cada interacción es única, como un solo musical.  
- **Fusión tecnológica:** HTML audiovisual clásico + Web3 + IA.  
- **Experiencia inmersiva:** El usuario deja de ser espectador pasivo y se convierte en protagonista.  

---

## 6. Roadmap SDD
1. **Definir especificaciones**: Documentar requerimientos y módulos clave.  
2. **Diseñar arquitectura modular**: Separar frontend, backend, base de datos y blockchain.  
3. **Implementar prototipo base**: Reproductor audiovisual con HTML5 + React.  
4. **Integrar interactividad avanzada**: Hotspots, panel social y gamificación.  
5. **Conectar Web3**: Minting de NFTs y recompensas ERC‑20.  
6. **Optimizar con IA**: Recomendaciones y análisis de interacción.  
7. **Validar y desplegar**: Testing, seguridad y publicación en Vercel/Netlify.  

---

## 7. Impacto en Portafolio
Este documento asegura que el proyecto se presente como:  
- Una evolución de tu trabajo académico en HTML audiovisual.  
- Una pieza innovadora que combina música, arte y tecnología.  
- Una demostración clara de tu perfil como **ingeniero consultivo y creativo**.
